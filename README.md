# Blinky

Followed this excellect [tutorial](https://www.youtube.com/watch?v=dxgufYRcNDg) by [@therustbits](https://www.youtube.com/@therustybits) and modified it slightly.

Intead of just blinking in the primary colors, I used an RNG to calculate random rgb colors.

## setup

- scaffolding generated with [esp-generate](https://github.com/esp-rs/esp-generate).

- requires [espflash](https://github.com/esp-rs/espflash) to flash the program to the esp32
